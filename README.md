# Demolition Lovers — Acto XXIV (2026 Remastered)

![Gothic Theme](assets/images/icons8-goth-48.png)

Una experiencia web inmersiva de estética gótica inspirada en **My Chemical Romance**, diseñada exclusivamente para celebrar el cumpleaños de **Aranxita** el **23 de Abril de 2026**.

## ✦ Características Principales

- **Acto XXIV:** Un tributo visual a los 24 años de legado musical y personal, con tipografías clásicas (`Cinzel`, `IM Fell English`) e iconografía victoriana-gótica.
- **Atmósfera Gótica Realista:** Efectos de goteo de sangre con iluminación realista, partículas de ceniza en suspensión y niebla volumétrica renderizada en Canvas.
- **CVN Legacy (Crónica de Vida Nocturna):** Un lienzo interactivo donde el usuario puede dejar su marca "sobre el abismo" utilizando un pincel de brillo sanguíneo neón.
- **Oráculo de la Rosa:** Interacción mística con respuestas aleatorias inspiradas en la lírica de Gerard Way y el universo de *Three Cheers for Sweet Revenge*.
- **Diseño Adaptativo Premium:** Totalmente optimizado para dispositivos móviles, eliminando elementos innecesarios para garantizar la legibilidad en pantallas pequeñas sin perder la esencia visual.

## ✦ Tecnologías Utilizadas

- **HTML5/CSS3:** Uso extensivo de variables CSS (`:root`), gradientes radiales y animaciones avanzadas.
- **JavaScript (Vanilla):** Lógica personalizada para el sistema de partículas (Ashes) y el generador de poemas.
- **GSAP (GreenSock):** Motor principal para animaciones fluidas y efectos de *ScrollTrigger* que dan vida a la narrativa.
- **Canvas API:** Renderizado de alta eficiencia para los sistemas de niebla y el lienzo interactivo CVN.

## ✦ Instalación y Ejecución

La página es un sitio estático puro. No requiere servidores complejos ni instalaciones de Node.js.

1. Descarga el repositorio o los archivos del proyecto.
2. Abre `demolition-lovers.html` en cualquier navegador moderno (Chrome o Edge recomendados).
3. **Recomendación:** Para la mejor experiencia de desarrollo, usa la extensión **Live Server** de VS Code para previsualización inmediata.

## ✦ Optimización de Rendimiento (v2026.1)

- Reducción de carga de CPU mediante la limitación de partículas activas en pantalla.
- Uso de `will-change` para optimizar el renderizado del navegador (GPU acceleration).
- Mergeo de capas de goteo SVG para reducir el cálculo de trazado (Path calculation).
